# 🎵 TikTak - TikTok Clone Platform

A full-stack TikTok Clone built with Node.js, Express, MongoDB, Socket.io, and Flutter.

## 🚀 Features
- 📱 Vertical Video Feed (Infinite Swipe)
- 🎥 In-App Video Recording & Cloud Upload
- 💬 Real-Time Live Comments (Socket.io)
- 👤 User Profiles, Followers & Following Feed
- 🔍 Explore & Search (#Hashtags & Users)
- ⚡ Video Pre-Caching for Smooth Playback

## 🛠️ Tech Stack
- **Backend:** Node.js, Express, MongoDB, Socket.io, Cloudinary
- **Frontend:** Flutter / Dart
